## 개요
 
길드원들의 캐릭터 정보(레벨·직업·아이템레벨·전투력)를 파티를 꾸릴때마다 일일이 검색하는게 번거로웠다. Google Apps Script로 자동화하려고 했는데, 이때 API와 JS를 둘 다 처음 다뤘다.<br>
Gemini로 코드를 짜긴 했는데, 왜 의도대로 작동하지 않는지 Gemini가 잡아내지 못했다. 결국 생활코딩 JS 기초 강의를 3일간 빠르게 훑고 나서야, 코드를 직접 읽으며 문제를 짚을 수 있었다.
<br>
 
## 접근 방식
 
- **처음엔 캐릭터 정보 페이지를 그대로 긁어오려 했다 — 안 됐다** <br>
    페이지 자체가 자바스크립트로 데이터를 그려내는 구조라, Apps Script의 `UrlFetchApp`으로 받아온 HTML에는 정작 캐릭터 정보가 비어 있었다. 브라우저처럼 화면에 그림을 그려주는 게 아니라, 서버에 요청만 보내고 응답을 그대로 받아오는 방식이다 보니 자바스크립트가 실행되기 전 빈 뼈대만 받아온 것이었다.
- **개발자도구로 실제 데이터가 오는 API를 찾아냈다** <br>
    캐릭터 정보 페이지가 화면에 데이터를 채울 때 몰래 호출하는 API 엔드포인트(`/api/search/aion2/search/v2/character`)를 직접 찾아, 페이지 대신 이 API를 호출하는 방식으로 바꿨다.
- **브라우저인 척, 헤더를 채워 넣었다** <br>
    직접 요청을 보내니 서버가 이상한 접근으로 판단해 막았다. `Referer`와 `User-Agent`를 실제 브라우저 값으로 채워 넣고 나서야 정상적으로 데이터가 돌아왔다.
- **닉네임으로 먼저 캐릭터 ID를 찾고, 그 ID로 상세정보를 한 번 더 요청했다** <br>
    검색 API가 돌려주는 이름에는 `<strong>` 태그가 섞여 있어서, 정규식으로 태그를 제거한 뒤 정확히 일치하는 이름만 골라냈다.
<br>

## 기술 스택
- Google Apps Script (UrlFetchApp, SpreadsheetApp)
- REST API 직접 호출 (JSON 파싱, 요청 헤더 위조)
- 정규식 (HTML 태그 제거)
- Gemini (코드 작성 보조) + 생활코딩 JS 기초 (자기학습)

<br>

## 기술적 도전과 해결
 
**문제 1: Gemini가 짜준 코드가 왜 안 되는지 이해할 수 없었다**
- 원인: JS와 API 개념 자체가 없어서, Gemini의 설명을 들어도 무엇이 틀린 말인지 구분할 지혜가 없었다.
- 해결: 생활코딩 JS 기초 강의로 3일간 문법과 개념을 먼저 익혔다.
- 결과: 이후로는 Gemini가 짠 코드를 직접 읽고, 막히는 지점을 짚어가며 함께 고칠 수 있게 됐다.
<br>

**문제 2: 일반적인 페이지 추출 방식으로는 데이터가 비어 있었다**
- 원인: 캐릭터 정보 페이지가 자바스크립트로 화면을 그리는 구조라, HTML 자체에는 데이터가 없고 페이지가 열린 뒤 별도 API 요청으로 데이터를 채워 넣고 있었다. 게다가 서버가 `Referer` 등을 검사해 직접 요청을 걸러내고 있었다.
- 해결: 개발자도구 네트워크 탭에서 실제 데이터가 오가는 API를 찾아내고, 브라우저 요청과 동일한 헤더를 채워 우회했다.
- 결과: HTML을 파싱할 필요 없이, 훨씬 안정적으로 JSON 데이터를 바로 받아오는 구조를 완성했다.
<br>
<br>

## 코드 샘플
 
닉네임으로 캐릭터를 검색하고, ID로 상세정보를 가져오는 핵심 함수
<br>

    ```javascript
    function checkIdExtraction(name) {
    const url = `https://aion2.plaync.com/ko-kr/api/search/aion2/search/v2/character?keyword=${encodeURIComponent(name)}&race=2&serverId=2015&page=1&size=30`;
    
    // 브라우저가 요청하는 것처럼 Referer / User-Agent를 채워 우회
    const options = {
        "headers": {
        "Referer": "https://aion2.plaync.com/",
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 ..."
        }
    };
    
    const json = JSON.parse(UrlFetchApp.fetch(url, options).getContentText());
    const charList = json.list;
    
    // 검색 결과의 <strong> 태그를 제거하고 정확히 일치하는 이름만 매칭
    const exactMatch = charList.find(c => c.name.replace(/<\/?[^>]+(>|$)/g, "") === name);
    
    if (exactMatch) {
        const infoUrl = `https://aion2.plaync.com/api/character/info?lang=ko&characterId=${exactMatch.characterId}&serverId=2015`;
        const infoJson = JSON.parse(UrlFetchApp.fetch(infoUrl, options).getContentText());
        const itemLevelObj = infoJson.stat.statList.find(s => s.type === "ItemLevel");
    
        return {
        level: infoJson.profile.characterLevel || 0,
        className: infoJson.profile.className || "-",
        totalPower: infoJson.profile.combatPower || 0,
        itemLevel: itemLevelObj ? itemLevelObj.value : 0
        };
    }
    }
    ```
 <br>

길드원 시트를 순회하며 자동으로 채워 넣는 실행 함수
<br>

    ```javascript
    function updateAionData() {
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("길드원 리스트");
    const names = sheet.getRange("A5:A" + sheet.getLastRow()).getValues();
    
    names.forEach((row, i) => {
        const name = row[0];
        if (!name) return;
        Utilities.sleep(500);
    
        try {
        const res = checkIdExtraction(name);
        const rowNum = i + 5;
        if (res) {
            sheet.getRange(rowNum, 3).setValue(res.level);
            sheet.getRange(rowNum, 4).setValue(res.className);
            sheet.getRange(rowNum, 5).setValue(res.itemLevel);
            sheet.getRange(rowNum, 6).setValue(res.totalPower);
        } else {
            sheet.getRange(rowNum, 3).setValue("ID 미발견");
        }
        } catch (e) {
        sheet.getRange(i + 5, 3).setValue("에러");
        }
    });
    }
    ```

## 결과
 
- 3일 만에 JS를 읽고 고칠 수 있게 됐다. 그전까지는 AI가 짜준 코드를 그대로 믿을 수밖에 없었는데, 이후로는 어디가 문제인지 스스로 짚을 수 있었다.
- 페이지를 직접 스크래핑하는 대신, 그 뒤에서 실제로 데이터를 나르는 API를 찾아 호출하는 방식을 처음으로 익혔다. API라는 개념을 알게 되자 신세계가 열렸다. 세상이 정보로 가득했다.
- 길드원 리스트 시트를 갱신 할 때 레벨·직업·아이템레벨·전투력이 자동으로 채워지는 시스템을 완성해 파티 생성을 더욱 쉽게 했다.
