## 개요
 
다른 업무에 밀려 손도 못 대고 쌓인 서류 작업이 있었다. 스캔된 신청서·의사확인서·세부내역서·영수증 파일들을 건별로 모아 PPT 슬라이드로 정리해야 하는 일이었는데, 밀린 양이 거의 한 분기치였다.<br>
납기는 이미 못 맞추는 게 확정적인 상황이었다.
<br>
 
## 접근 방식
 
- **파일명 자체를 키값으로 설계했다** <br>
    하이픈으로 구분된 세 부분(건 번호-서류유형코드-파일ID)으로 파일명 규칙을 직접 짰다. 이 키값을 기준으로 같은 건에 속한 파일들을 자동으로 그룹화했다.
- **필수 서류 체크를 딕셔너리 기반으로 만들었다** <br>
    봉투·의사확인서·세부내역서·영수증 4종을 딕셔너리로 관리해, 서류 종류가 늘어나도 코드 구조를 바꾸지 않고 한 줄만 추가하면 되게 설계했다.
<br>

## 기술 스택
- Excel VBA (Scripting.FileSystemObject, Scripting.Dictionary)
- PowerPoint Object Model (슬라이드 복제·이미지 배치 자동화)
- GPT (코드 작성 보조)
<br><br>

## 기술적 도전과 해결
 
**문제 1: 처음 짜보는 매크로라, 완벽한 코드를 한 번에 쓰려고 했다**
- 원인: 코드를 쪼개는 감각이 없어서, 하나의 거대한 매크로로 모든 걸 해결하려 했다.
- 해결: CS 전공인 남자친구에게 "쪼개서 만들고 실행해야 한다"는 지적을 계속 받으면서, 메인함수와 서브함수를 나누고 디버깅하는 법을 개념적으로 이해했다.
- 결과: 원하는 결과가 나올 때까지 프롬프트를 몇 번이고 다시 짰고, 출퇴근길에 GPT와 C언어를 개념적으로 익힌 것도 코드 구조를 이해하는 데 도움이 됐다. 이 시행착오를 반복하면서 프롬프트 작성 능력이 가장 크게 늘었다. 
<br>

**문제 2: 클로드가 없던 시절, 아키텍쳐라 부를만한 코드가 안 나왔다**
- 원인: 파일명 파싱, 그룹화, 누락 서류 감지까지 요구사항이 많아 프롬프트 한 번으로는 부족했다.
- 해결: 이 당시에는 쪼개야 한다는 개념을 '프로세스를 쪼개는 것'만으로 한정하고 있어서 사람이 하는 행동을 쪼개되, 루프문으로 적용하는 방식으로 접근했다.
- 결과: 프로세스별로 코드를 쪼개는 습관이 생겼다. 
<br>

## 코드 샘플
 
파일명을 키값으로 파싱·그룹화

<br>

    ```vba
    ' 파일명을 하이픈 기준으로 3부분으로 분리 (건번호-서류유형-파일ID)
    firstHyphenPos = InStr(file.Name, "-")
    secondHyphenPos = InStr(firstHyphenPos + 1, file.Name, "-")
    
    part1 = Left(file.Name, firstHyphenPos - 1)                          ' 건 번호
    part2 = Mid(file.Name, firstHyphenPos + 1, secondHyphenPos - firstHyphenPos - 1) ' 서류유형 코드
    dotPos = InStrRev(file.Name, ".")
    part3 = Mid(file.Name, secondHyphenPos + 1, dotPos - secondHyphenPos - 1)        ' 파일 ID
    
    ' 같은 건 번호(키값)를 가진 파일들을 하나의 그룹으로 묶음
    fileGroupKey = part1
    If groupedFiles.exists(fileGroupKey) Then
        groupedFiles(fileGroupKey) = groupedFiles(fileGroupKey) & "," & file.Name
    Else
        groupedFiles.Add fileGroupKey, file.Name
    End If
    ```
<br>
필수 서류 자동 감지
<br>

    ```vba
    ' 필수 서류 체크리스트를 딕셔너리로 관리 — 서류 종류가 늘어나도 한 줄만 추가하면 됨
    Set requiredDocs = CreateObject("Scripting.Dictionary")
    requiredDocs.Add "00E", "봉투"
    requiredDocs.Add "03D", "의사확인서"
    requiredDocs.Add "05S", "세부내역서"
    requiredDocs.Add "04R", "영수증"
    
    ' 그룹 내 존재하는 서류와 대조해 누락된 것만 골라 코멘트로 표시
    For Each docKey In requiredDocs.Keys
        If Not existingDocs.exists(docKey) Then
            If missingDocs <> "" Then missingDocs = missingDocs & ", "
            missingDocs = missingDocs & requiredDocs(docKey) & " 미비"
        End If
    Next docKey
    ```
<br>

## 결과
 
- 1분기 동안 처리해야 했던 분량을 1주일 만에 끝냈다. 절대 못 맞출 것 같던 납기를 지켰다.
- 매크로 자체보다, 이때 늘어난 프롬프트 작성 능력과 함수 구조를 나눠 짜는 습관이 이후 다른 자동화 프로젝트의 기반이 됐다.
